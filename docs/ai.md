# IA

AIProviderInterface con respuestas JSON estructuradas y schema validation.

Usos permitidos: extracción de RUT/folio/contraparte, clasificación, ranking de candidatos, explicación y anomalías.

La IA no aprueba ni modifica información financiera directamente. Cada salida registra proveedor/modelo/schema/confianza y puede recibir feedback humano.
